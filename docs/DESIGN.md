# Cantos — World Epic Explorer

## What

An interactive web experience for exploring the world's great epics — Mahabharata, Ramayana, Iliad, Odyssey, and more. Combines scholarly depth with visual storytelling through family trees, timelines, character exploration, and cross-cultural comparison.

## Core Features

### 1. Epic Catalog
- Browse world epics by region, era, tradition
- Cards with key info: origin, author, language, themes

### 2. Interactive Family Trees
- Expandable/collapsible genealogy trees
- Mahabharata: Kuru dynasty, Pandavas, Kauravas
- Ramayana: Raghu dynasty, Ayodhya line
- Click nodes for character deep-dives

### 3. Character Explorer
- Cross-epic character profiles
- Relationships, key events, symbolic roles
- Find characters across traditions (e.g., "the exile hero" pattern)

### 4. Narrative Timeline
- Scrollable chronological view of epic events
- Filter by epic, character, theme

### 5. Comparative Lens
- Side-by-side theme analysis (dharma vs honor, exile, war)
- Pattern detection across cultures

## Tech Stack
- **Next.js 14** (App Router, static + dynamic)
- **TypeScript**
- **Tailwind CSS** (styling)
- **Framer Motion** (animations)
- **D3.js / React Flow** (family trees, timelines)
- **Vercel** (deployment)

## Name Origin
"Cantos" — the sections of a long poem. Each epic is a canto in the larger human story.
